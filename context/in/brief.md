## Step 1: Implement ReadCache in fork.rs

**Files:** `apps/mirage-rs/src/fork.rs`

**Creates:** A working in-memory cache layer for account and storage reads, with TTL-based eviction and hit-rate tracking.

**Imports:**
- `use std::collections::HashMap;`
- `use std::time::{Duration, Instant};`
- `use lru::LruCache;`
- `use alloy_primitives::{Address, U256, B256};`
- `use revm::primitives::AccountInfo;`

**Action:**

1. In the `ReadCache` struct, add private fields:
   - `account_cache: LruCache<Address, (AccountInfo, Instant)>` — LRU for account lookups with insertion time
   - `storage_cache: LruCache<(Address, U256), (U256, Instant)>` — LRU for storage slot lookups
   - `block_hashes: LruCache<u64, (B256, Instant)>` — cached block hashes
   - `hits: u64` and `misses: u64` — for hit_rate calculation

2. Implement `ReadCache::new(capacity: usize, ttl: Duration) -> Self`:
   - Construct LRU caches with `capacity` (default 1000 accounts, ~10k slots)
   - Set `self.hits = 0` and `self.misses = 0`

3. Implement `ReadCache::get_account(&mut self, address: &Address) -> Option<AccountInfo>`:
   - Check if `(address, now)` is in cache and not expired (now - insertion_time < ttl)
   - If found and not expired, increment `self.hits` and return clone of AccountInfo
   - If found but expired, remove and increment `self.misses`
   - If not found, increment `self.misses`

4. Implement `ReadCache::insert_account(&mut self, address: Address, info: AccountInfo, _block_number: u64)`:
   - Insert `(address, (info.clone(), Instant::now()))` into `account_cache`
   - LRU automatically evicts if at capacity

5. Implement `ReadCache::get_storage(&mut self, address: &Address, slot: &U256) -> Option<U256>`:
   - Check if `((address, slot), now)` is in cache and not expired
   - Follow same hit/miss tracking as `get_account`

6. Implement `ReadCache::insert_storage(&mut self, address: Address, slot: U256, value: U256, _block_number: u64)`:
   - Insert `((address, slot), (value, Instant::now()))` into `storage_cache`

7. Implement `ReadCache::clear(&mut self)`:
   - Call `self.account_cache.clear()`, `self.storage_cache.clear()`, `self.block_hashes.clear()`
   - Reset `self.hits = 0` and `self.misses = 0`

8. Implement `ReadCache::hit_rate(&self) -> f64`:
   - Return `self.hits as f64 / (self.hits + self.misses) as f64` (handle division by zero → return 0.0)

9. Implement `ReadCache::entry_count(&self) -> usize`:
   - Return `self.account_cache.len() + self.storage_cache.len() + self.block_hashes.len()`

10. Implement `ReadCache::evict_to(&mut self, target_entries: usize)`:
    - While `entry_count() > target_entries`, pop LRU from largest cache (usually storage_cache)
    - Prioritize evicting storage over accounts to maintain critical account info
